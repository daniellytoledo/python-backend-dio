# 🐍 Guia Rápido: Gerenciamento de Ambientes e Dependências com Pipenv

Este resumo reúne os principais comandos e conceitos sobre o uso do **Pipenv** para gerenciar ambientes virtuais e pacotes em projetos Python.

---

## 📌 O que é o Pipenv?

O **Pipenv** é uma ferramenta oficial recomendada para gerenciar dependências e ambientes virtuais em projetos Python. Ele une as funcionalidades do `pip` (instalador de pacotes) e do `virtualenv` (criador de ambientes isolados) em um único fluxo de trabalho.

Ao utilizar o Pipenv, dois arquivos principais são gerados na raiz do projeto:
* **`Pipfile`**: Lista as dependências instaladas de forma simples e legível (substitui o tradicional `requirements.txt`).
* **`Pipfile.lock`**: Registra as versões exatas de cada pacote e suas subdependências, além de assinaturas digitais (*hashes*) para garantir segurança e reprodutibilidade em qualquer máquina ou servidor.

---

## ⚙️ Instalação do Pipenv

Caso ainda não tenha o Pipenv instalado globalmente no seu Python:

```bash
pip install pipenv
```

*(Nota para Windows: caso o terminal não reconheça o comando `pipenv` diretamente, utilize `python -m pipenv` antes de cada comando abaixo).*

---

## 🚀 Criando o Ambiente Virtual e Instalando Dependências

Ao instalar o primeiro pacote em uma pasta de projeto, o Pipenv cria automaticamente o ambiente virtual isolado e gera os arquivos `Pipfile` e `Pipfile.lock`.

### Exemplo instalando o Django:
```bash
pipenv install django
```

### Instalar a partir de um projeto existente (clonado do GitHub):
Se você baixou um repositório que já possui um `Pipfile`, basta rodar:
```bash
pipenv install
```

### Instalar uma dependência apenas para desenvolvimento (ex: ferramentas de teste ou formatação):
```bash
pipenv install pytest --dev
```

---

## 🔌 Ativando e Desativando o Ambiente Virtual

### Ativar o ambiente virtual (entrar no shell isolado):
```bash
pipenv shell
```

### Verificar se o ambiente está ativo (útil no Windows):
```bash
python -c "import sys; print(sys.prefix)"
```
*(Se o caminho exibido apontar para a pasta `.virtualenvs`, o ambiente está ativo).*

### Desativar o ambiente virtual (sair do shell):
```bash
exit
```

---

## 🔄 Atualizando e Removendo Dependências

### Atualizar todos os pacotes e o `Pipfile.lock`:
```bash
pipenv update
```

### Atualizar apenas um pacote específico (ex: Django):
```bash
pipenv update django
```

### Verificar pacotes desatualizados:
```bash
pipenv update --outdated
```

### Remover uma dependência:
```bash
pipenv uninstall django
```
