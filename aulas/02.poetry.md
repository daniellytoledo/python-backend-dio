# 🐍 Guia Rápido: Gerenciamento de Ambientes e Dependências com Poetry

Este resumo reúne os principais comandos e conceitos sobre o uso do **Poetry** para gerenciar ambientes virtuais, dependências e empacotamento em projetos Python.

---

## 📌 O que é o Poetry?

O **Poetry** é uma ferramenta moderna para gerenciamento de dependências, ambientes virtuais e publicação de pacotes em Python. Ele organiza toda a configuração do projeto em um único arquivo padrão da comunidade Python.

Ao utilizar o Poetry, dois arquivos principais controlam o projeto:
* **`pyproject.toml`**: Arquivo padrão que centraliza as informações do projeto, dependências principais e dependências de desenvolvimento.
* **`poetry.lock`**: Registra as versões exatas de todos os pacotes e subdependências instalados, garantindo que qualquer pessoa ou servidor instale exatamente o mesmo ambiente.

---

## ⚙️ Instalação do Poetry

### No Windows (PowerShell):
```powershell
(Invoke-WebRequest -Uri https://python-poetry.org -UseBasicParsing).Content | py -
```

### No Linux / macOS:
```bash
curl -sSL https://python-poetry.org | python3 -
```

### Verificar se a instalação funcionou:
```bash
poetry --version
```

---

## 🚀 Iniciando um Projeto e Criando o Ambiente Virtual

O Poetry cria o ambiente virtual automaticamente na primeira vez que você instala ou adiciona uma dependência.

### Criar um projeto novo do zero (já cria a estrutura de pastas):
```bash
poetry new nome-do-projeto
```

### Iniciar o Poetry em uma pasta de projeto que já existe:
```bash
poetry init
```

### Instalar dependências de um projeto existente (clonado do GitHub):
```bash
poetry install
```

---

## 📦 Instalando Dependências (Ex: Django)

### Adicionar uma dependência principal ao projeto:
```bash
poetry add django
```

### Adicionar uma dependência apenas para desenvolvimento (ex: testes ou linters):
```bash
poetry add pytest --group dev
```

## 🔌 Ativando e Desativando o Ambiente Virtual

*(Nota: Nas versões mais recentes do Poetry (2.0+), o comando `poetry shell` foi movido para um plugin separado. A forma recomendada e nativa de rodar comandos ou ativar o ambiente é usando `poetry env activate` ou `poetry run`).*

### Ativar o ambiente virtual no terminal atual:
```bash
eval \$(poetry env activate)
```
*(No PowerShell do Windows, rode `poetry env activate` e execute o caminho que ele exibir, ou instale o plugin com `poetry self add poetry-plugin-shell` para usar `poetry shell`).*

### Executar um comando direto dentro do ambiente sem precisar ativar o shell:
```bash
poetry run python manage.py runserver
```

### Verificar informações e o caminho do ambiente virtual ativo:
```bash
poetry env info
```

### Desativar o ambiente virtual (caso tenha ativado o shell):
```bash
deactivate
```
*(Ou `exit`, se estiver usando o `poetry-plugin-shell`).*

## 🔄 Atualizando e Removendo Dependências

### Atualizar todos os pacotes respeitando as regras do `pyproject.toml` e atualizar o `poetry.lock`:
```bash
poetry update
```

### Atualizar apenas um pacote específico (ex: Django):
```bash
poetry update django
```

### Listar pacotes instalados e verificar atualizações disponíveis:
```bash
poetry show --outdated
```

### Remover uma dependência:
```bash
poetry remove django
```
